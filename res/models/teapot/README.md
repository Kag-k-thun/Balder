# Utah teapot

The teapot of Martin Newell (University of Utah, 1975), whose data is in the public domain, as an OBJ of 3644 vertices
and 6320 triangles without normals (generated when the model is loaded).

Taken from [common-3d-test-models](https://github.com/alecjacobson/common-3d-test-models) (`data/teapot.obj`).
